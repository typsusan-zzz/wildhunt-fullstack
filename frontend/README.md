# 荒野追猎 Three.js 原型

这是一个基于 `Vite + TypeScript + Three.js` 的网页可试玩原型。

当前版本已经从“霓虹动物追猎”调整为“鲜艳卡通森林里的真假鹿捉迷藏”：

- 狼需要在倒计时结束前找出全部真人鹿。
- 鹿需要混进 AI 鹿群，撑到时间结束。
- 狼咬中真人鹿加时间，咬错 AI 鹿扣时间。
- 支持狼方和鹿方两种单机模拟模式。

## 启动

```bash
npm install
npm run dev
```

默认地址通常是：

```text
http://127.0.0.1:5173
```

## 当前内容

- 鲜艳卡通低模森林
- 第三人称跟随相机
- 狼方操作模式
- 鹿方伪装操作模式
- 真假鹿混群
- AI 鹿状态机：闲逛、停顿、吃草、张望、受惊短跑、恢复
- 狼方嗅探、标记、扑咬
- 咬中真人鹿 `+35s`
- 咬错 AI 鹿 `-20s`
- 鹿方饥饿值和可疑度
- 开始界面、角色选择、结算界面、再来一局
- 移动方向调试 UI
- 攻击范围调试开关
- 免费 GLB 狼模型和鹿占位模型
- AI 生成的卡通主视觉和技能图标素材

## 操作

```text
WASD / 方向键：移动
Shift：冲刺
鼠标拖动：转动视角
鼠标点击 / Space：狼方攻击
Q：狼方嗅探
E：狼方标记最近鹿
F：显示 / 隐藏攻击范围
1：鹿方吃草动作
2：鹿方张望动作
```

移动端会显示冲刺、嗅探、攻击按钮。

## 胜负规则

```text
初始倒计时：4 分钟
最大时间上限：6 分钟
真人鹿数量：4
AI 鹿数量：16
狼咬中真人鹿：+35 秒
狼咬错 AI 鹿：-20 秒
狼胜利条件：淘汰全部真人鹿
鹿胜利条件：时间耗尽前至少 1 名真人鹿存活
```
