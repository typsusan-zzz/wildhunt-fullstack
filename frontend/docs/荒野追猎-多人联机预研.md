# 《荒野追猎》多人联机预研

## 结论

单机原型完成并确认好玩后，再进入多人联机。

推荐方案：

```text
Node.js + Colyseus + WebSocket
```

理由：

- 适合房间制小游戏。
- TypeScript 前后端模型可复用。
- 天然支持房间、状态同步、重连和消息广播。
- 后续能迁移到微信小游戏或抖音小游戏的 WebSocket 环境。

## 联机规模

第一版联机规模：

```text
1 名狼玩家 vs 2-4 名鹿玩家 + 12-20 只 AI 鹿
```

## 服务端权威范围

服务端必须权威处理：

- 玩家位置
- 鹿状态
- 狼攻击命中
- 误伤 AI 鹿
- 找出真人鹿
- 时间加减
- 胜负结算

客户端可以预测：

- 本地移动
- 镜头
- UI 反馈
- 临时特效

## 同步模型

推荐状态结构：

```ts
type RoomState = {
  phase: 'waiting' | 'playing' | 'result';
  timeLeft: number;
  wolfPlayerId: string;
  deerPlayerIds: string[];
  foundReal: number;
  mistakes: number;
  actors: Record<string, ActorState>;
};

type ActorState = {
  id: string;
  role: 'wolf' | 'deer' | 'aiDeer';
  x: number;
  z: number;
  yaw: number;
  state: string;
  hunger?: number;
  suspicion?: number;
  dead: boolean;
};
```

## 消息设计

客户端发送：

```text
input_move
input_sprint
wolf_attack
wolf_sniff
wolf_mark
deer_action
```

服务端广播：

```text
state_snapshot
attack_result
time_changed
deer_found
round_result
player_reconnected
```

## 命中校验

狼攻击命中由服务端校验：

- 攻击者必须是狼。
- 目标必须在攻击半径内。
- 攻击冷却必须结束。
- 目标不能已经死亡。
- 如果目标是真人鹿，增加时间并记录找到。
- 如果目标是 AI 鹿，扣时间并记录误伤。

## 断线重连

重连策略：

- 房间保留玩家状态 60 秒。
- 鹿玩家断线后暂时由 AI 行为接管。
- 狼玩家断线后暂停 10 秒，超过时间则房间结束或转移房主。
- 重连后下发完整状态快照。

## 后续实施顺序

1. 抽离共享类型。
2. 建立 Colyseus 房间。
3. 接入本地移动同步。
4. 接入狼攻击和结算。
5. 接入鹿方动作与饥饿值。
6. 加入断线重连。
7. 做移动端弱网测试。
